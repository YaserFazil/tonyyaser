## 🛠️ Technology Stack:

- **Framework**: Next.js 14 (App Router) - SEO & Performance
- **Styling**: Tailwind CSS + CSS Modules
- **Animations**: Framer Motion + GSAP (for complex animations)
- **3D Effects**: Three.js (optional, for advanced effects)
- **Particles**: Particles.js or react-particles
- **Icons**: Lucide React or React Icons
- **Typography**: Inter or JetBrains Mono (for code feel)
- **Forms**: React Hook Form
- **Deployment**: Vercel (optimized for Next.js)
